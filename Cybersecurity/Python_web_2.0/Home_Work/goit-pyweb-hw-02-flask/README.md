1. Видаліть старий контейнер (він займає ім'я):
docker rm -f my-web-bot

2. Перезберіть образ (щоб оновити utils.py):
docker build -t my-bot-image .

3. Запустіть ПРАВИЛЬНОЮ командою (з портом):
docker run -p 5000:5000 -v ${PWD}/data:/app/data --name my-web-bot my-bot-image

*💡 Порада на майбутнє
Щоб контейнер автоматично видалявся після того, як ви його зупините (або якщо він впаде з помилкою), додавайте прапорець --rm у команду запуску.

Тоді команда виглядатиме так:
docker run -p 5000:5000 --rm -v ${PWD}/data:/app/data --name my-web-bot my-bot-image


###  Пояснення команди запуску

* `-v ${PWD}/data:/app/data`: Це магія збереження даних.
    * `${PWD}/data` — це папка `data` на **вашому комп'ютері**.
    * `/app/data` — це папка `data` **всередині контейнера**.
    * Docker з'єднує їх. Коли бот пише файл всередині, він з'являється у вас на диску.
* `--name my-web-bot`: Ми дали ім'я контейнеру, щоб легше ним керувати.
* `my-bot-image`: Ім'я образу, який ми створили
