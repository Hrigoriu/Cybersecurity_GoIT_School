>_ RetroQuotesDB

Аналітика проєкту: Retro-Tech Quotes Database

Цей розділ надає загальне розуміння суті застосунку. Тут зібрано ключові цілі та технологічні рішення, які роблять цей проєкт потужним інструментом для бекенд-портфоліо.

Що це таке?

Це консольний пошуковий застосунок для цитат, створений на Python. Він побудований на основі чистої багатошарової архітектури та стилізований під ретро-термінал.

Чому цей проєкт сильний для портфоліо?

  • Багатошарова архітектура (Layered Architecture)
  • Cache-first підхід (Redis) для оптимізації читання
  • Хмарні інтеграції (MongoDB Atlas)
  • Separation of Concerns (розділення відповідальності)
  • Конфігурація через змінні середовища

Архітектура та Кешування

У цьому розділі візуалізовано внутрішню будову застосунку. Ви можете побачити, як запити проходять через шари системи (SOLID) та як Redis допомагає оптимізувати повторні звернення до бази даних.

Модель Даних (MongoEngine)

Цей блок демонструє структуру NoSQL бази даних. Відносини між авторами та їхніми цитатами реалізовані через об'єктно-орієнтоване відображення (ODM) із використанням ReferenceField.

Процес Розгортання та Запуску

Покроковий посібник з налаштування середовища. Натисніть на кроки, щоб відкрити детальні інструкції та команди.

Використовуйте сучасний інструмент Poetry для керування залежностями:

git clone <your-repository-url>
cd retro-tech-quotes-db
poetry install

Створіть файл .env у корені проєкту (не додавайте в git!):

MONGODB_URI=mongodb+srv://<user>:<pass>@cluster0...
REDIS_HOST=localhost
REDIS_PORT=6379

Ніколи не публікуйте .env у відкритих репозиторіях!

Запустіть Redis через Docker та очистіть БД перед імпортом:

docker run --name redis-cache -p 6379:6379 -d redis
poetry run python clean_db.py
poetry run python main.py
