# 🕷️ Scrapy Quotes Retro-Tech Scraper

Цей проєкт реалізує багаторівневу архітектуру для збору даних з сайту quotes.toscrape.com за допомогою фреймворку Scrapy.

Проєкт побудований з дотриманням принципів SOLID та DRY, використовує Poetry для керування залежностями та має кастомний консольний вивід у стилі Retro-Tech Terminal. Усі зібрані дані (цитати та інформація про авторів) зберігаються локально у формати JSON та автоматично синхронізуються з хмарною базою даних MongoDB Atlas.

## 🌟 Основні можливості

- Scrapy Engine: Швидкий асинхронний збір даних з пагінацією.
- SOLID Архітектура: Чітке розділення логіки на шари (Models, Repository, Service, Scraper, Controller).
- MongoDB Integration: Автоматичний запис даних у хмару з перевіркою на дублікати та створенням зв'язків (ReferenceField).
- Retro-Tech Logger: Кастомне стилізоване логування процесів замість стандартного "шумного" виводу Scrapy.
- Безпека: Використання .env для захисту облікових даних до бази даних.

```text

│   │   └── repository.py       # Шар доступу до даних (Repository)
│   ├── services/
│   │   └── data_service.py     # Бізнес-логіка (Service)
│   └── scraper/
│       ├── items.py            # DTO для Scrapy
│       ├── settings.py         # Налаштування Scrapy
│       ├── pipelines.py        # Шлях обробки даних (JSON + DB)
│       └── spiders/
│           └── quotes_spider.py # Сам павук
```

## 🚀 Встановлення та запуск

### Крок 1. Клонування репозиторію та встановлення залежностей

Відкрийте термінал у папці проєкту та виконайте:

```text
poetry install
```

### Крок 2. Налаштування змінних оточення

Створіть файл .env у кореневій папці проєкту (на одному рівні з pyproject.toml) та додайте туди ваш рядок підключення до MongoDB:

```text
MONGODB_URI=mongodb+srv://<vash_login>:<vash_parol>@cluster0.xxxxx.mongodb.net/quotes_db?retryWrites=true&w=majority
```

(Увага: Замініть <vash_login> та <vash_parol> на ваші реальні дані з MongoDB Atlas, без використання дужок < >).

### Крок 3. Запуск краулера

Активуйте віртуальне середовище та запустіть головний скрипт:

```text
poetry shell
python src/main.py
```
