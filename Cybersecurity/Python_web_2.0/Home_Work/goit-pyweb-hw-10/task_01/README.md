# 🌿 Django Eco-Quotes Web App

Цей проєкт — це сучасний веб-додаток на базі фреймворку **Django**, який є функціональним аналогом сайту `quotes.toscrape.com`. Інтерфейс виконаний у стилі **Eco‑Minimalism** (шавлієвий зелений та вугільний кольори, багато вільного простору) за допомогою **Tailwind CSS**.

Проєкт розроблено з дотриманням стандартів **PEP 8**, принципів **SOLID** (виокремлення бізнес-логіки у сервіси) та **DRY**. Для керування залежностями використовується **Poetry**, а основною базою даних є **PostgreSQL**.

## 🌟 Основні можливості

- **Автентифікація:** Повноцінна система реєстрації, входу та виходу користувачів.
- **Управління контентом (CRUD):** Лише авторизовані користувачі можуть додавати нових авторів та цитати.
- **Публічний доступ:** Перегляд списку всіх цитат, детальної сторінки автора та фільтрація доступні без авторизації.
- **Навігація та Фільтрація:** Пагінація списку цитат та віджет "Top 10 tags" для фільтрації за найпопулярнішими тегами.
- **Scraping Service:** Вбудований інструмент для автоматичного збору цитат та біографій авторів з оригінального сайту безпосередньо через веб-інтерфейс (тільки для авторизованих).
- **Безпека:** Жодних захардкоджених паролів чи ключів у коді — використовується файл `.env`.

## 📁 Архітектура проєкту

Для дотримання принципу єдиної відповідальності (SRP) логіку розділено на додатки та сервіси:

```text
django_quotes/
├── .env                        # Секрети (Ніколи не комітити!)
├── pyproject.toml              # Файл конфігурації Poetry
├── core/                       # Головні налаштування (settings, urls)
├── users/                      # Додаток автентифікації
├── quotes/                     # Головний додаток (моделі, контролери, сервіси)
│   ├── models.py               # Схеми бази даних
│   ├── services.py             # Бізнес-логіка (Scraping)
│   ├── forms.py                # Форми для додавання контенту
│   └── views.py                # Контролери
└── templates/                  # Eco-Minimalism UI (Tailwind)
```

## 🚀 Встановлення та налаштування

Відкрийте термінал у VS Code (Ctrl + ~) у порожній папці, де буде ваш проєкт.

### 1. Ініціалізація Poetry та залежності у файлі pyproject.toml

Виконайте команди для створення віртуального середовища та встановлення пакетів:

```text
poetry init -n
poetry add django psycopg2-binary django-environ requests beautifulsoup4
```

Або використайте готовий pyproject.toml:

```text
[tool.poetry]
name = "scrapy-quotes-retro"
version = "0.1.0"
description = "Hybrid Django + Scrapy + MongoDB + PostgreSQL project"
authors = ["Hrigoriu Programmer <Hrigoriu@gmail.com>"]
package-mode = false

[tool.poetry.dependencies]
python = "^3.12"

# Django stack
django = "^5.2"
psycopg2-binary = "^2.9.12"
django-environ = "^0.13.0"

# Scraping stack
scrapy = "^2.11.0"
requests = "^2.34.0"
beautifulsoup4 = "^4.14.3"

# MongoDB stack
mongoengine = "^0.27.0"
pymongo = "4.3.3"

# Utilities
python-dotenv = "^1.0.1"
colorama = "^0.4.6"

[build-system]
requires = ["poetry-core"]
build-backend = "poetry.core.masonry.api"

[tool.poetry.group.dev.dependencies]
black = "^25.0"
flake8 = "^7.0"
isort = "^6.0"
```

 замініть створений файл цим кодом і виконайте:

```text
poetry install
```

### 2. Активізація віртуального середовища

```text
poetry shell
```

---

### 3. Створення структури Django

```text
django-admin startproject core .
python manage.py startapp quotes
python manage.py startapp users
```

---

### 4. Конфігурація та Безпека (База даних та змінні оточення)

- **Відкрийте програму pgAdmin,
- **Підключіться до вашого сервера (Server: PostgreSQL 17, port: 5432, username: postgres, password: 123456).
- **Створіть нову порожню базу даних із назвою quotes_db.
- **Створіть файл .env у кореневій папці проєкту та додайте туди конфігурацію:

```text
SECRET_KEY=django-insecure-ваша-дуже-секретна-фраза-тут
DEBUG=True
# Вкажіть ваші реальні дані до локальної PostgreSQL: postgres://користувач:пароль@хост:порт/назва_бд
DATABASE_URL=postgres://postgres:123456@localhost:5432/quotes_db
```

## 🧩 Структура файлів (Розподіл логіки)

Проєкт складається з наступних ключових файлів, які відповідають за свої унікальні функції:

### Конфігурація: core/settings.py (Налаштування підключення до БД та додатків)

### Моделі Даних (Postgres): quotes/models.py (Схеми для Author, Quote, Tag)

### Бізнес-Логіка (Scraping): quotes/services.py (Ізольована логіка обходу сторінок та збору даних)

### Контролери (Views)

- quotes/views.py (Пагінація, фільтрація за тегами, обробка форм).
- quotes/views.py (Детальна сторінка автора).
- users/views.py (Реєстрація, логін, логаут).

### Форми: quotes/forms.py (Валідація вводу для авторів та цитат)

### Маршрутизація (URLs)

- core/urls.py (Головний роутер).
- quotes/urls.py (Маршрути цитат).
- users/urls.py (Маршрути користувачів).

### Eco-Minimalism Інтерфейс UI (Шаблони)

- Розміщуються у папці templates/ (включаючи base.html, сторінки цитат, форми авторизації).
- Створіть папку templates у корені проєкту (на одному рівні з manage.py).
- Всередині створіть папки quotes та users.
- Вміст
  - файл: templates/base.html
  - файл: templates/quotes/quote_list.html
  - файл: templates/quotes/add_author.html
  - файл: templates/quotes/add_quote.html
  - файл: templates/quotes/author_detail.html
  - файл: templates/users/login.html
  - файл: templates/users/register.html

## ▶️ Фінальний запуск (Міграції та Сервер)

У терміналі VS Code (де активовано poetry shell) виконайте наступні кроки:

### 1. Створіть таблиці в PostgreSQL

```text
python manage.py makemigrations
python manage.py migrate
```

### 2. Створіть суперкористувача (Адміністратора)

```text
python manage.py createsuperuser
```

### 3. Запустіть сервер розробки

```text
python manage.py runserver
```

### 4. Відкрийте браузер

- введіть у браузері

```text
http://127.0.0.1:8000/
```

- увійдіть в систему та натисніть кнопку "Завантажити з сайту (Scrape)" у шапці сайту, щоб автоматично наповнити базу даних авторами та цитатами!
