# ENT-Vision AI: Ukrainian Token Optimizer 🐭🇺🇦

Проєкт для оптимізації роботи з OpenAI API при використанні кириличного (українського) тексту. Завдяки інтеграції бібліотеки **Dormouse**, проєкт дозволяє економити **50–70% бюджету на токенах**, не втрачаючи при цьому якість відповідей моделі.

## 🛠 Технологічний стек

* **Мова:** Python 3.12+
* **Менеджер пакетів:** Poetry
* **AI Engine:** OpenAI (через `DormouseClient` middleware)
* **Бібліотеки:** `openai`, `python-dotenv`, `dormouse-ua`

## 🚀 Швидкий старт

### 1. Підготовка середовища

Клонуйте репозиторій та встановіть залежності через Poetry:

```bash
# Клонування бібліотеки-оптимізатора
git clone [https://github.com/ChuprinaDaria/dormouse.git](https://github.com/ChuprinaDaria/dormouse.git)

# Встановлення залежностей проєкту
poetry install
poetry add ./dormouse
```

### 2. Конфігурація OpenAI API

Конфігурація (.env)

Створіть файл .env у корені проєкту та додайте свій ключ:

```bash
OPENAI_API_KEY=sk-proj-ваш_ключ_тут
```

### 3. Запуск

Виконайте скрипт через віртуальне середовище Poetry:

```bash
poetry run python kirilica_ai.py
```

### 📂 Структура проєкту

kirilica_ai.py — основний робочий файл із реалізацією DormouseClient.
dormouse/ — локальна копія бібліотеки для стиснення тексту.
.env — конфігураційний файл для безпечного зберігання API ключів.
pyproject.toml — опис залежностей та налаштувань Poetry.

💡 Як це працює?
Проєкт використовує Dormouse Middleware, який автоматично:
Перехоплює український текст перед відправкою до OpenAI.
Стискає кириличні токени в компактніші латинські замінники (функція squeeze).
Модель GPT обробляє текст, а клієнт автоматично розпаковує відповідь назад в українську мову.
